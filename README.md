# numerical-analysis-schemes
Simple implementations of iterative and matrix schemes from my course in Numerical Analysis at IIT Hyderabad

# Summary:
1. Iterative schemes for finding roots of a polynomial: [iterativeSchemes.py](https://github.com/v-samyuktha/numerical-analysis-schemes/tree/main/iterativeSchemes.py)
   
  - Bisection method  
  - Secant method
  - Newton-Raphson method
  - Regula-Falsi method
  - General iterative scheme

2. Matrix schemes: [matrixSchemes.py](https://github.com/v-samyuktha/numerical-analysis-schemes/tree/main/matrixSchemes.py)  

    **Direct Methods & Matrix Operations**
  - Gauss elimination
  - LU Decomposition (Doolittle method)
  - Matrix inversion
  
    **Iterative Solvers for Linear Systems (Ax = b)**
  - Gauss-Jacobi method
  - Gauss-Seidel method
  
    **Eigenvalue & Eigenvector Algorithms**
  - Given's method (QR factorization approach)
  - Power method (Dominant eigenvalue isolation)
